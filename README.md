# 皇者天下（單機版）

《皇者天下》核心樂趣的單機化改編：保留三國題材、城池經營、武將養成、戰略攻防，移除伺服器與多人連線依賴，改為 AI 勢力對抗、章節戰役與事件戰。純手機觸控 HTML5 遊戲，多檔案結構（`index.html` + `css/` + `js/`），用手機瀏覽器打開即可遊玩，不需安裝、不需伺服器。

## 如何開始遊玩

用手機瀏覽器直接打開 `index.html`（**直立持機**）。遊戲會自動存檔在裝置的瀏覽器儲存空間裡，關閉分頁或離線一段時間後再打開，之前設定的建造/練兵/研究/行軍都會依照實際經過的時間自動繼續推進（就像正常的手機策略遊戲一樣）。

## 操作方式（純觸控）

- **單指拖曳**：平移地圖視角
- **單指輕點**：選取／查看／下令
- 下方主選單可切換：城池／地圖／武將／軍隊／戰役／戰報

## 遊戲內容（MVP）

- 1 張大地圖、3 個勢力（玩家 + 2 個 AI 勢力）
- 11 種基礎建築（主城、糧倉、伐木場、採石場、金礦、倉庫、兵營、校場、工坊、酒館、學院、城牆），各 10 級
- 學院科技樹（經濟／軍事／城防三大類）
- 30 名武將，透過劇情任務與地圖探索獲得（不做抽卡機制），各有專屬技能會實際影響戰鬥數值
- 武將裝備系統（武器／甲冑／坐騎／寶物），透過戰役獎勵與擊破野外據點取得
- 部隊編成、行軍、攻城、防守，戰鬥採即時結算＋戰報
- 15 個主線戰役關卡，含官渡、赤壁、夷陵等史詩事件戰
- 隨機事件（商隊、流民、山賊等），離線時也會自動處理不卡關
- 成就系統
- 存讀檔與離線進度推進（絕對時間戳計時，離線再久也能正確追趕）
